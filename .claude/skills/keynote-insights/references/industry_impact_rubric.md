# 行业影响分析框架

PPT 每页"行业影响"bullet 的写作指南。用来保证分析角度一致，避免每页都是"这个功能很酷"的空话。

## 3 条 bullet 的固定轴线

**Bullet 1 — 对手机软件品类**
这个特性会蚕食 / 重塑哪一类第三方 App？它是不是让某个品类从"独立 App"降级为"系统能力"？
- 例：Live Translation → Google Translate / Microsoft Translator 独立 App 使用频次会下滑。
- 例：Liquid Glass → 第三方 UI 主题 / 图标包 App 的差异化价值被抹平。

**Bullet 2 — 对周边硬件 / 独立硬件品类**
有没有一类专门的硬件因为这个系统级特性变得没必要买？或者反而需要新硬件配合？
- 例：Live Translation + AirPods → 讯飞 / Pocketalk 等翻译机的核心场景被吞；但会刺激 AirPods / 耳机的换机。
- 例：Workout Buddy → 苹果进一步吞食独立健身 App（Freeletics、Peloton 的单机订阅价值减弱）。

**Bullet 3 — 对开发者生态 / 平台政策**
这个特性会让开发者多一个 API 可调（生态扩张），还是被平台"自家先做"（生态挤压）？有无对应的开发者 session / 新 framework？
- 例：Foundation Models framework → 中小 App 免费吃到端侧 LLM，云端 LLM 调用收入被挤压。
- 例：App Intents 新增 → Shortcut 生态升级，也绑死在 Apple 平台。

## 写作风格

- 每条 **≤ 35 字**（1 行显示）。
- 结论先行：先说"谁会受影响"，再说"怎么影响"。
- 可量化就量化："用户使用频次"、"品类规模"、"占比"。
- 不用"很"、"非常"、"极大"等空泛副词。

## 观点标题（thesis）写作

单页最顶那一行深红大标题，是全页的结论。写作要求：

- **句式**：主语（特性/产品）+ 动作（吞并/重塑/颠覆/挤压/抬高）+ 宾语（行业/品类）。
- **长度**：10-20 字。
- **示例**：
  - `实时翻译：苹果正式吞并翻译机品类`
  - `Liquid Glass：把"主题美化"拉回系统默认`
  - `Foundation Models：端侧 LLM 免费给开发者了`
  - `Workout Buddy：健身 App 的差异化窗口正在关闭`
- **避免**：
  - ❌ "实时翻译功能非常实用"（空话）
  - ❌ "新功能介绍：实时翻译"（无观点）
  - ❌ "苹果发布 AirPods 新功能"（流水账）

## 对冲 / 边界

每条行业影响 bullet，如果过去有过"苹果做过但失败"的相似前例（比如 Ping、iTunes U、HomePod 1 代），建议在引述环节里带一条对冲视角（例如 Gruber / Ben Thompson 指出的风险）。
